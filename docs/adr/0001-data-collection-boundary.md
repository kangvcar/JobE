# 数据采集以合法来源为主干，商业招聘平台只做小样本登录态采集

主流商业招聘平台在 2026 年已无稳定可复现的采集路径（BOSS 直聘的主包会主动检测 CDP 连接并重载页面，51job 与智联分别由阿里云 WAF 和腾讯云 EdgeOne 拦截，拉勾网运营主体已于 2026 年 5 月进入破产重整），且淘宝天猫诉爬虫案判决已将"突破登录验证、IP 限制、滑块验证"明确列为不正当竞争的构成要素。因此主干数据来自人社部中国公共招聘网、Moka ATS 公开 API、Job-SDF 与 Chinese-SkillSpan 等合法来源，商业平台仅在猎聘上以人工扫码登录、单 IP 串行、低频只读的方式采集数千条样本，用于证明真实采集能力。

## Considered Options

全量真实爬取四大平台被否决：技术上 BOSS 的签名网关叠加指纹与反 CDP 检测已无公开可用绕过手段，法律上突破技术措施是判例中的加重情节，且演示现场随平台改版翻车的概率很高。完全放弃商业平台也被否决：会失去"具备真实采集能力"这一说服点，而合法来源本身同样需要真实采集实现。

## Consequences

不得声称遵守平台用户协议——BOSS 与猎聘的协议均将"拟人程序"列为禁止行为；可站住的表述仅限于不突破技术措施、不采集个人信息、低频只读。采集账号必须为专用测试账号，登录态文件不入库、不进版本控制。任何来源的采集结果一律先落为快照，分析层只读快照，以保证第三方可在无网络、不触发平台风控的条件下复现全部结论。人社部数据中的联系人姓名与电话属于个人信息，在入库前丢弃。
