# 用 Neo4j 存储图谱，理由是建模范式与可读性，不是性能

本项目的图规模（千级节点、十万级边、遍历不超过三跳）落在业界公认"PostgreSQL 足够"的区间内，真正会跑的查询里没有一类需要免索引邻接。选择 Neo4j 社区版是因为它对实体版本化与时间切片对比有官方文档化的建模范式，Cypher 表达"对比两个时点的能力项差异"远比递归 CTE 可读，且知识图谱领域的读者对它的接受度最高。

## Consequences

这是一笔为开发效率和可读性付出的运维成本，不应被误读为性能需求。数据访问层必须抽象为仓储接口，使切换到 PostgreSQL 不需要改动业务代码。Neo4j 社区版为 GPLv3，仅约束分发行为；若将来需要把数据库随交付物一起分发给客户，须重新评估许可。Kuzu 已于 2025 年 10 月归档，Memgraph 与 ArangoDB 均已转为非开源许可，三者都不作为备选。
