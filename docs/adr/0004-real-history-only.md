# 演化分析的时间轴只用真实历史数据，不生成合成历史

从项目启动时开始采集只能得到向前的短序列，而演化分析需要多年跨度。补齐历史的办法是引入真实的可回溯来源：含职位描述正文与发布时间的历史招聘数据集、Job-SDF 的月度技能需求序列，以及 GitHub 事件归档、arXiv、PyPI/npm 下载量、HuggingFace 模型发布时间这类技术领先信号。用大模型生成历史职位被明确排除，那是幻觉的源头且一经问出即致命。

## Consequences

技术信号与招聘需求之间的领先滞后期成为一个可实测的参数，而不是假设，这把"职位时滞"从缺陷变成了模型里的可观测量。Stack Overflow 不作为技术热度的领先指标：其月发帖量自 2016 年峰值已下跌约 98%，且有分析实测其动能与招聘需求呈负相关，跨 2022 年直接做领先滞后分析会得出反向结论。本体版本必须冻结并记录，否则跨年比较会混入编码变更造成的假信号。
