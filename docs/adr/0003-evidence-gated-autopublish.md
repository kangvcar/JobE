# 幻觉防控靠证据强制与 AI 审核员，而非全量人工审核

产品要求尽可能自动化，而图谱的科学性要求每条结论可追责，两者的交集是把人从审核回路里换成机器但保留强制约束：任何抽取结果必须携带能定位到原文位置的证据，拿不出证据的直接丢弃；随后由一条独立的校验链路（换模型、换提示、回原文取证）判断结论是否被证据支持，通过即自动发布并标注证据等级。

## Consequences

只有四类动作会被人工拦截：新兴岗位首次正式发布、既有岗位核心必备技能被删除、统计信号与 AI 审核员结论相矛盾、用户举报后的处置。其余变更全部自动发布，进变更流水并可回滚，由专家事后抽检。抽取环节中大模型只做语义判断，绝不输出坐标或位置——位置一律由确定性的字符串匹配回填，匹配不上即判为抽取失败，这条规则同时充当幻觉过滤器。
